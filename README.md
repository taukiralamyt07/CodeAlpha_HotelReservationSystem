# CodeAlpha Hotel Reservation System

A console-based Java hotel booking application demonstrating OOP, room categorization, searching availability, reservations, cancellations, simulated payment, booking details, and file persistence.

## Features
- Standard, Deluxe, and Suite rooms
- Search available rooms by category
- Make and cancel reservations
- Automatic booking IDs
- Payment simulation
- Booking details display
- Persistent booking/room data using Java serialization (`bookings.dat`)

## Run
```bash
javac src/Main.java
java -cp src Main
```
